# Formula

Parse a composition string into `(element, count)` pairs, normalize
indices, and sort/filter/count lists of formulas. New in cifkit 1.2.1
(migrated from `bobleesj.utils`). See the
[Elemental data tutorial](../tutorials/elemental_data) for worked
examples.
